# Resumen
El estudio propone un modelo de ensamble híbrido (GJR-GARCH-SVR-LSTM) para pronosticar la volatilidad del crudo WTI (spot y futuros). El modelo utiliza los parámetros del GJR-GARCH (que captura el efecto apalancamiento) como variables de entrada para un modelo SVR (que captura relaciones no lineales) y un modelo LSTM (que captura dependencias de largo plazo). Además, se incorporan variables exógenas como el VIX, el índice GPR, tasas de interés, precios del oro y temperatura. Los autores evalúan el modelo con métricas de error (HMSE, HMAE) y con la Efectividad de Cobertura (HE) mediante el Ratio de Cobertura Óptimo (OHR). **El estudio se excluye del corpus porque la conferencia no cumple el criterio de calidad editorial (C3).**

# 1. Método y Datos

**¿Qué se predice exactamente?**
La **volatilidad del crudo WTI** (spot y futuros), calculada como una **varianza móvil de 21 días sobre los retornos logarítmicos diarios**:
$$\sigma^2_t = \text{Var}(r_{t-20}, \dots, r_t)$$
donde $r_t = \ln(P_t/P_{t-1})$. **No usan Volatilidad Realizada (RV) de alta frecuencia.** Es un proxy suavizado y de baja frecuencia, más fácil de predecir que la RV diaria y menos útil para gestión de riesgo a 1 día.

**Fuente de los datos:**
- **EIA (WTI).** Precios spot y futuros del WTI. Periodo: 2000–2023.
- **Data availability:** no se declara explícitamente. Los precios son públicos (EIA).

**Partición Temporal:** **Walk-forward cross-validation (ventana móvil).** Excelente práctica para evitar el look-ahead bias en series de tiempo. El modelo se reentrena en cada ventana. Esto es una fortaleza metodológica.

**¿La predicción es rolling o hold-out? ¿Open-loop o recursiva?** **Rolling con reentrenamiento, open-loop con actuales (implícito).** El esquema walk-forward implica que el modelo se reentrena en cada paso usando solo datos hasta $t$, y se evalúa sobre $t+1$. No se declara explícitamente si la predicción es open-loop con actuales o recursiva, pero dado que es multi-step (7, 14, 21, 28 días) y se reentrena, lo más probable es open-loop con actuales.

**Normalización:** el paper menciona que se hizo un preprocesamiento para asegurar la estacionariedad y normalidad, pero **no detalla** si usaron Min-Max o StandardScaler, ni si se ajustó solo con el train set.

**Ingeniería de Características:**
- **Variables endógenas:** retornos del crudo, variables técnicas (Bandas de Bollinger, EMA, log-retornos, log-retornos al cuadrado).
- **Variables exógenas:** demanda/oferta global, inventarios de EE. UU., tipos de cambio EUR/USD y JPY/USD, tasas de interés, inflación, índice de riesgo geopolítico (GPR), índice VIX, precio del oro y temperatura.
- **Variables del GARCH:** los parámetros estimados por el GJR-GARCH ($\omega, \alpha, \beta, \gamma$) se utilizan como features de entrada para SVR y LSTM.
- **Sin descomposición:** no hay EMD, VMD ni filtros no causales.

**Conversión de frecuencia:** los datos semanales y mensuales se convirtieron a frecuencia diaria usando *forward filling*. Esto puede introducir ligeros sesgos al usar información del pasado para rellenar, pero no es una fuga grave si se hace antes del split.

# 2. Arquitectura Final (GJR-GARCH-SVR-LSTM)

El modelo propuesto es un **ensamble secuencial en serie** (no en paralelo). La predicción de un modelo se convierte en el input del siguiente:
1. **Etapa 1 — GJR-GARCH:** se estima el modelo sobre los retornos logarítmicos diarios. Se extraen los parámetros estimados $\omega, \alpha, \beta, \gamma$. Estos parámetros actúan como "features" que resumen el estado de la volatilidad condicional.
2. **Etapa 2 — SVR:** recibe como inputs los parámetros del GJR-GARCH + las 15 variables exógenas y técnicas. Captura las relaciones no lineales. Genera una predicción intermedia de la volatilidad.
3. **Etapa 3 — LSTM:** recibe como inputs la predicción del SVR + los inputs originales del GJR-GARCH + las variables exógenas. Procesa la secuencia temporal para capturar dependencias de largo plazo. Aplica Dropout, Early Stopping y Adaptive Learning Rates. Genera la predicción final.

**Arquitectura interna:** **NO reportada.** No se reportan el número de capas del LSTM, el número de neuronas por capa, el dropout final, el learning rate final ni el kernel del SVR. Solo se menciona el uso de Dropout, Early Stopping y Adaptive Learning Rates para el LSTM, y que se hizo tuning para el SVR, pero sin detalles.

# 3. Resultados y Comparaciones

**Modelos comparados (4 en total):**
- **GJR-GARCH:** modelo base univariado.
- **GJR-GARCH-SVR:** híbrido con parámetros GARCH + variables exógenas.
- **GJR-GARCH-LSTM:** híbrido con parámetros GARCH + variables exógenas.
- **GJR-GARCH-SVR-LSTM:** ensamble secuencial.

**Métricas de Evaluación:**
- **Punto:** HMSE, HMAE.
- **Cobertura:** Efectividad de Cobertura (HE) mediante el Ratio de Cobertura Óptimo (OHR).

**Ganador y Rendimiento:**
El modelo **GJR-GARCH-SVR-LSTM** es el ganador. Resultados para el periodo 2016–2019 (a 7 días vista):
- HMSE: reducción del 51.58% frente al GJR-GARCH.
- HMAE: reducción del 33.09% frente al GJR-GARCH.
- HE: mejora de 89.07% a 92.45%.

Para el periodo 2016–2023 (incluyendo COVID), a 7 días vista:
- HMSE: reducción del 47.93%.
- HMAE: reducción del 32.22%.
- HE: mejora de 87.41% a 89.36%.

**Pruebas de Significancia:**
**NO se reportan pruebas de significancia estadística** (ni Diebold-Mariano, ni MCS, ni Clark-West). La comparación se basa únicamente en promedios de métricas (HMSE, HMAE y HE).

**Sesgo de Reporte:**
Alto. Cuatro problemas:
1. **Comparación estructuralmente injusta:** el GJR-GARCH base es univariado (solo usa retornos históricos). El ensamble utiliza los parámetros del GARCH + 15 variables exógenas + variables técnicas. Es imposible saber si el ensamble es mejor por su arquitectura o porque le dieron mucha más información. La comparación justa sería entre los modelos de ML que reciben los mismos inputs (SVR vs LSTM vs Ensamble).
2. **Target suavizado:** la varianza móvil de 21 días es un target más suave y fácil de predecir que la RV diaria. Los resultados no son comparables con estudios que usan RV de alta frecuencia.
3. **Falta de pruebas de significancia:** no se puede afirmar que las diferencias sean estadísticamente significativas. Solo se comparan valores puntuales de HMSE, HMAE y HE.
4. **Falta de detalle arquitectónico:** no se reportan el número de capas, neuronas, dropout ni el kernel del SVR. La reimplementación exacta no es posible.
