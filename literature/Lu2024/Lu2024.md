# Resumen
El estudio propone un modelo híbrido (KV-MFSCBA-G) para el pronóstico del **precio** del crudo WTI y Brent. El modelo descompone la serie de precios utilizando VMD optimizado por divergencia KL (KL-VMD), clasifica los componentes en alta y baja frecuencia mediante Entropía Difusa (FE), y luego utiliza dos enfoques para predecirlos: una red CNN-BiLSTM-Attention (CBA) de frecuencia mixta para los componentes de baja frecuencia (incorporando el índice macroeconómico mensual GECON) y un modelo GARCH para los componentes de alta frecuencia. Finalmente, usa el algoritmo de optimización Sparrow Search Algorithm (SSA) para ajustar los hiperparámetros. **El estudio se excluye del benchmark porque su variable objetivo es el precio, no la volatilidad.**

# 1. Método y Datos

**¿Qué se predice exactamente?**
El **precio spot diario** del crudo WTI y Brent (en USD/barril). No predice la Volatilidad Realizada (RV) ni la volatilidad condicional. El GARCH se usa únicamente para modelar el componente de alta frecuencia del precio, pero el resultado final es el nivel de precio agregado. Es un caso de **mislabeling** similar a Wu2024, Wang2020 y Mohsin2023: el abstract menciona "volatility" pero el target empírico es el precio.

**Fuente de los datos:**
- **Precios:** WTI (2 ene 1986 – 21 feb 2023, 9,357 obs) y Brent (20 may 1987 – 21 feb 2023, 9,077 obs) obtenidos de la US Energy Information Administration (EIA).
- **Variable exógena:** Índice mensual Global Economic Conditions (GECON) de Baumeister et al. (2022).
- **Data availability:** "Available by corresponding author upon request". Los precios son públicos (EIA); el GECON es público.

**Partición Temporal:** split estático 90% train / 10% test. Cronológico. Fechas de corte explícitas:
- WTI: train hasta 29 may 2019 (8,421 obs); test hasta 21 feb 2023 (936 obs).
- Brent: train hasta 25 jul 2019 (8,169 obs); test hasta 21 feb 2023 (908 obs).

**¿La predicción es rolling o hold-out? ¿Open-loop o recursiva?** **Hold-out estático, esquema de input no declarado.** El modelo se entrena una vez sobre el 90% inicial y se evalúa una vez sobre el 10% final. No hay reentrenamiento entre puntos. No se declara si la predicción es open-loop con actuales o recursiva.

**Normalización:** aplicaron normalización a los datos (Min-Max implícito para redes neuronales). **No reporta** si el escalador se ajustó solo con el train set.

**Ingeniería de Características (LOOK-AHEAD BIAS CONFIRMADO):**
- **KL-VMD sobre la serie completa:** en la Sección 4.2, aplican la descomposición KL-VMD sobre la **serie completa de precios (1986–2023)** antes de dividir en train/test. Los modos (IMFs) calculados para el train set contienen información matemática del futuro (test set). Es el mismo patrón de fuga por descomposición global que en Ouyang2024, Wu2023 y Gong2025.
- **Feature selection (FE):** la clasificación de los IMFs en alta/baja frecuencia se aplica sobre los IMFs calculados con la serie completa, por lo que hereda la fuga.
- **GECON y MIDAS:** el índice macroeconómico mensual se alinea con los datos diarios usando MIDAS. Esto es causal si se usa solo información pasada, pero no se declara explícitamente si el MIDAS usa rezagos o valores contemporáneos.
- **Tuning de Hiperparámetros (SSA):** el Sparrow Search Algorithm se usa para optimizar el número de unidades ocultas, iteraciones y batch size de la red CBA. **No se especifica** si el SSA se evaluó usando el set de validación o directamente el set de prueba (riesgo de sobreajuste y data leakage).

# 2. Arquitectura Final (KV-MFSCBA-G)

El modelo tiene tres etapas:
1. **Paso 1 — Descomposición y Clasificación:**
   - Se aplica KL-VMD al precio para obtener K=7 modos. El valor de K y el factor de penalización α se optimizan minimizando la divergencia KL. Para WTI: K=7, α=900. Para Brent: K=7, α=2100.
   - Se usa Entropía Difusa (FE) para clasificar los modos: FE < 0.05 son "términos de tendencia de baja frecuencia" (IMF1–IMF2) y FE > 0.05 son "términos de perturbación de alta frecuencia" (IMF3–IMF7).
2. **Paso 2 — Pronóstico de Componentes:**
   - **Baja Frecuencia (MF-CBA):** se usa una red CNN-BiLSTM-Attention de Frecuencia Mixta. Se utiliza la técnica MIDAS para alinear el GECON mensual con los datos diarios. Los hiperparámetros se optimizan con SSA.
   - **Alta Frecuencia (ARIMA-GARCH):** se aplica un modelo ARIMA-GARCH a los componentes de alta frecuencia (IMF3–7) para capturar el agrupamiento de volatilidad y el ruido.
3. **Paso 3 — Ensamblaje:** se suman las predicciones de todos los componentes (baja + alta frecuencia) para obtener el precio final.

**CNN-BiLSTM-Attention (arquitectura):**
- Capa CNN (convolución 1D, pooling, dropout).
- Capa BiLSTM (forward y backward).
- Capa Attention (asigna pesos a los estados ocultos).
- Capa Dense de salida.
- Optimización con SSA: población de 10 sparrows, 10 iteraciones máximas. Rangos de búsqueda: hidden units ∈ [50, 500], iterations ∈ [50, 500], batch size ∈ [100, 1000].
- **No se reportan** el número de capas CNN, filtros, kernel size, neuronas BiLSTM ni dropout final.

# 3. Resultados y Comparaciones

**Modelos comparados (10 en total):**
- **Base:** LSTM, VMD-LSTM (V-L), KL-VMD-LSTM (KV-L), KL-VMD-SSA-LSTM (KV-SL).
- **Descomposición-Ensamblaje:** EMD-SSA-LSTM-GARCH (E-SL-G), EMD-MF-SSA-LSTM-GARCH (E-MFSL-G), EMD-MF-SSA-CBA-GARCH (E-MFSCBA-G), KL-VMD-SSA-LSTM-GARCH (KV-SL-G), KL-VMD-MF-SSA-LSTM-GARCH (KV-MFSL-G), KL-VMD-MF-SSA-CBA-GARCH (KV-MFSCBA-G).
- **Literatura:** ARIMA, ARIMA-GARCH, ANN, ELM, SVM, XGBoost, EEMD-GRU, EEMD-LSTM, VMD-SVM-ARMA.

**Métricas de Evaluación:**
MAE, RMSE, MAPE. Pruebas de significancia: Model Confidence Set (MCS) con 5,000 bootstrap, y Diebold-Mariano (DM).

**Ganador y Rendimiento:**
El modelo **KV-MFSCBA-G** es el ganador absoluto. En el set de prueba de WTI:
- RMSE = 1.3871, MAE = 0.5836, MAPE = 0.0299.

En Brent:
- RMSE = 0.6707, MAE = 0.3714, MAPE = 0.0096.

**Pruebas de Significancia:**
MCS con 5,000 bootstrap, a nivel de significancia 0.25. El modelo propuesto es el único que se mantiene en el conjunto superior $\hat{M}^*_{75\%}$ con p-valor = 1.0 en casi todos los indicadores. El DM test confirma su superioridad estadística frente a todos los benchmarks (p < 0.05).

**Sesgo de Reporte:**
Alto. Cuatro problemas:
1. **Target inválido para el corpus:** predice precio, no volatilidad. Es la razón de exclusión.
2. **Look-ahead bias por descomposición global:** KL-VMD se aplica sobre la serie completa antes del split. Los IMFs del train contienen información del test.
3. **Tuning sospechoso:** el SSA se usa para ajustar los hiperparámetros de la red, pero no se especifica un set de validación independiente. El fitness podría calcularse sobre el test set.
4. **Comparación injusta contra benchmarks de la literatura:** los benchmarks (ARIMA, SVM, ANN, etc.) usan solo el precio histórico, mientras que el modelo propuesto usa descomposición (KL-VMD) + variables exógenas (GECON) + optimización (SSA). La comparación justa sería contra los modelos de la familia de descomposición-ensamblaje (E-SL-G, KV-SL-G, etc.), que sí reciben los mismos inputs.

**Fortalezas del reporte:**
- **Ablation study limpio:** 10 modelos que aíslan el efecto de cada componente (KL-VMD vs VMD vs EMD, MF vs no-MF, LSTM vs MFLSTM vs MFCBA, SSA vs no-SSA, GARCH vs no-GARCH).
- **MCS y DM formales:** usa pruebas de significancia con bootstrap.
- **Robustez en dos activos:** WTI y Brent.
- **Comparación con algoritmos de optimización:** SSA vs SOA vs PSO.
