# Resumen
El estudio propone un marco de pronóstico de volatilidad para datos de alta frecuencia que integra características econométricas, topológicas (redes complejas) y de volatilidad básica. La arquitectura central es un modelo de dos ramas (LSTM para patrones globales y TSMixer para patrones locales) unidas por un mecanismo de fusión dinámica por compuertas (Dynamic Gating). Además, los autores vinculan los pronósticos de volatilidad con la Teoría de Valores Extremos (EVT) para calcular el VaR y el ES, y aplican valores SHAP para la interpretabilidad. **El estudio se incluye porque predice volatilidad realizada de alta frecuencia, usa partición temporal y pruebas de significancia formales, aunque requiere correcciones de reporte y de protocolo.**

# 1. Método y Datos

**¿Qué se predice exactamente?**
La raíz cuadrada de la **Volatilidad Realizada (RV)** diaria, calculada a partir de datos intradía de 5 minutos:
$$\sigma_n = \sqrt{RV_n} = \sqrt{\sum_{i=2}^{112} \left(\ln(P_{n,i}) - \ln(P_{n,i-1})\right)^2}$$
**Este paper sí predice volatilidad realizada de alta frecuencia**, no un proxy de precio. Se evalúan horizontes de 1, 2 y 5 pasos.

**Fuente de los datos:**
- **Wind database.** Futuros de crudo de China (INE). Periodo: 27 de marzo de 2018 al 21 de octubre de 2024 (1,594 días de negociación). Se usan 112 nodos por día (intervalos de 5 minutos).
- **Data availability:** “Data will be made available on request”. Los precios son accesibles vía Wind (de pago) o fuentes públicas del exchange.

**Partición Temporal:**
- **Generación de features econométricas:** las predicciones de los modelos GARCH/HAR se generan con una **ventana móvil de 510 días**. Para predecir el día $t$, solo se usan datos hasta $t-1$. **No hay look-ahead bias en la creación de inputs econométricos.**
- **Partición para la red neuronal:** una vez generado el dataset histórico de predicciones (hasta 2024), se divide **estáticamente** en 70% train (para tuning y entrenamiento) y 30% test. La red se entrena una vez y se congela para el test set.
- **No hay rolling retraining de la red neuronal.** Los inputs son rolling, pero el modelo profundo no se reentrena en cada paso.

**¿La predicción es rolling o hold-out? ¿Open-loop o recursiva?**
**Hold-out estático para la red, con features econométricas rolling.** El modelo se entrena una vez sobre el 70% inicial y se evalúa una vez sobre el 30% final. No se declara explícitamente si la predicción multi-step es directa o recursiva, ni si el esquema de input es open-loop con actuales o closed-loop.

**Normalización:**
Se aplica `Min-Max Scaler` antes del entrenamiento:
$$X' = \frac{X - X_{\min}}{X_{\max} - X_{\min}}$$
**No se especifica** si el escalador se ajustó solo con el train set o con el dataset completo. Esto es una ambigüedad con riesgo potencial de fuga.

**Ingeniería de Características (16 variables):**
- **Básicas (B, 5):** log-precio, retorno absoluto, y raíces cuadradas de RV, CV (volatilidad continua) y JRV (volatilidad de saltos).
- **Econométricas (P, 6):** predicciones forward rolling de GARCH, GJR-GARCH, TGARCH, EGARCH, RGARCH-Itô-Jump (RGIJ) y HAR-RV. Generadas con ventana móvil de 510 días.
- **Topológicas (Net, 5):** fuerza de la red (S), densidad (D), eficiencia (E), coeficiente de agrupamiento (C) y transitividad (T), extraídos de una Red de Visibilidad Bidireccional Ponderada construida con los 112 precios intradía de cada día.
- **Sin descomposición de señal:** no hay EMD, VMD ni filtros no causales.

# 2. Arquitectura Final (M14: LSTM-TSMixer-C-Gate)

El modelo propuesto, denominado **M14 (All_TSMixer_LSTM_C_Gate)**, es una arquitectura de extracción y fusión profunda de características:

1. **Front-end (extracción de características):** recibe las 16 variables y las procesa en paralelo por dos ramas.
2. **Rama global — LSTM:** red LSTM de 2 a 4 capas que captura dependencias temporales de largo plazo.
3. **Rama local — TSMixer:** red basada en MLPs que mezcla información temporal y de características para capturar patrones locales abruptos.
4. **Back-end — fusión dinámica por compuertas (Concatenation Gating):**
   - Se concatenan las salidas de ambas ramas.
   - Pasan por una capa Dense con activación `Tanh`.
   - Pasan por una capa Dense con activación `Sigmoid` para generar la compuerta $G_C$.
   - Se aplica una conexión residual ponderada:
     $$h_C = G_C \odot h_{LSTM} + (1-G_C) \odot h_{TSMixer}$$
   - Salida final: $y_n = W^\top h_C + b$.
5. **Medición de riesgo:** Teoría de Valores Extremos (POT) para calcular VaR y ES.

**Funciones de pérdida y criterios:**
- **Entrenamiento:** el paper **no reporta explícitamente** la función de pérdida usada para la retropropagación.
- **Tuning:** se usa **MAE** como métrica para guiar la optimización de hiperparámetros y controlar el error general de predicción.
- **Evaluación en test:** MSE, MAE, HMSE (Heteroskedasticity-adjusted MSE) y HMAE (Heteroskedasticity-adjusted MAE).
- **Criterio de ganador:** menores valores en las cuatro métricas, validado con MCS y Clark-West.

# 3. Resultados y Comparaciones

**Modelos comparados (16 en total):**
- **Econométricos (M1–M6):** GARCH, GJR-GARCH, TGARCH, EGARCH, RGARCH-Itô-Jump, HAR-RV. Reciben solo 1 variable o variables específicas (retornos, CV/JV, RV diaria/semanal/mensual).
- **Deep Learning simple (M7–M10):** All_TSMixer, All_LSTM, P_LSTM, Net_LSTM. Reciben las 16 variables o subconjuntos.
- **Híbridos (M11–M16):** All_TSMixer_LSTM_A, All_TSMixer_LSTM_A_Gate, All_TSMixer_LSTM_C, All_TSMixer_LSTM_C_Gate (M14), P_TSMixer_LSTM_C_Gate, Net_TSMixer_LSTM_C_Gate. Reciben las 16 variables o subconjuntos.

**Métricas y Rendimiento:**
El modelo **M14** es el ganador. Resultados para 1 paso:
- MSE = $2.315 \times 10^{-5}$
- MAE = $3.060 \times 10^{-3}$
- HMSE = 0.106
- HMAE = 0.217

Frente a GARCH (M1), reduce MSE, MAE, HMSE y HMAE en 62.860%, 54.260%, 80.935% y 62.129%, respectivamente. Frente a LSTM puro (M8), reduce en 2.731%, 6.422%, 18.462% y 11.789%. Frente a M13 (concatenación sin gate), reduce en 3.381%, 3.774%, 5.357% y 4.824%.

**Pruebas de Significancia:**
- **MCS:** M14 es el único modelo con p-valor = 1.000 en las cuatro métricas para $h=1$ y $h=5$; en $h=2$ también pasan M12 y M14.
- **Clark-West:** M14 supera a la mayoría de benchmarks con estadísticos > 1.96 (5%).
- **Riesgo:** M14 obtiene el menor ALF y FZG, y pasa el MCS con p=1 en VaR/ES. Backtesting UC/IND/CC: todos los modelos pasan a $h=1$ y $h=2$ al 5%; a $h=5$, el GARCH de baja frecuencia no cumple UC/CC.

**Sesgo de Reporte:**
Moderado. Dos problemas principales:
1. **Comparación injusta contra modelos econométricos:** los modelos M1–M6 reciben solo 1 variable (o variables específicas), mientras que los modelos DL reciben las 16 variables. La comparación M14 vs GARCH es estructuralmente injusta; la comparación justa es dentro del bloque DL (M14 vs M7–M13), donde todos reciben los mismos inputs.
2. **Normalización ambigua:** no se especifica si el `MinMaxScaler` se ajustó solo con train.

**Fortalezas del reporte:**
- Target genuino de RV de alta frecuencia.
- Features econométricas rolling sin look-ahead.
- Ablation study con 16 modelos que aísla componentes (TSMixer vs LSTM vs gate vs features topológicas).
- Pruebas de significancia MCS y Clark-West.
- Evaluación de riesgo VaR/ES con EVT y backtesting.
- Robustez con diferentes splits, ventanas y mercado (SSE Energy Index).
- Interpretabilidad con SHAP.

5. **Semilla:** fijar una semilla.

**Riesgo de divergencia del desempeño reportado:** **medio.** El estudio no tiene fuga evidente en las features econométricas (rolling 510 días). La partición es temporal. **Advertencia sobre comparabilidad de resultados.** Dadas las carencias identificadas, valores finales de hiperparámetros no reportados, función de pérdida no declarada, conjunto de validación para tuning no especificado, normalización ambigua, esquema de predicción no declarado y ausencia de código, **no se puede asegurar que los resultados de la reimplementación sean comparables a los reportados en el artículo**.
