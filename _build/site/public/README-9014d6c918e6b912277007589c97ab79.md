# Predicción de Volatilidad del Crudo Brent: Una Perspectiva Moderna

El petróleo crudo Brent es una de las materias primas más negociadas a nivel mundial y sirve como referencia para la fijación de precios en los mercados internacionales. Su dinámica de precios está influenciada por eventos geopolíticos, interrupciones en el suministro y decisiones de la Organización de Países Exportadores de Petróleo y sus aliados (OPEP+), lo que genera una función de volatilidad con saltos abruptos y regímenes cambiantes. La crisis sanitaria global por COVID-19 en 2020 desplomó la demanda; la operación militar especial en Ucrania en 2022 elevó la incertidumbre geopolítica y los precios de la energía.

Este proyecto compara modelos econométricos clásicos (e.g., GARCH/EGARCH) con técnicas de Machine Learning (ML) y Deep Learning (DL) para modelar y pronosticar la dinámica del precio del crudo Brent, sus retornos y su volatilidad. La integración de noticias mediante Procesamiento de Lenguaje Natural (*Natural Language Processing*, NLP) se explora como vía para refinar la estimación de la volatilidad.

## Objetivos

- **Modelado econométrico de referencia:** Implementar modelos de volatilidad condicional (GARCH/EGARCH) como línea base cuantitativa.
- **Machine Learning (ML):** Entrenar algoritmos como Random Forest, XGBoost o SVR para la predicción de volatilidad.
- **Deep Learning (DL):** Desarrollar arquitecturas de redes neuronales recurrentes (LSTM, GRU) o convolucionales (TCN) para capturar dependencias temporales complejas.
- **Evaluación de riesgo:** Comparar el desempeño predictivo sobre la volatilidad realizada y la dinámica de retornos utilizando funciones de pérdida financieras (QLIKE, MSE) y métricas de precisión direccional.

*Trabajo futuro:* Extracción de señales geopolíticas a partir de noticias globales mediante NLP y su integración multimodal.

## Fuentes de datos

- **Series financieras:** Futuros diarios del crudo Brent (`BZ=F`) obtenidos de Yahoo Finance mediante `yfinance`.
  - **Período:** Ventana histórica de 10 años (2014 – presente).
  - **Variables:** Apertura, máximo, mínimo, cierre, cierre ajustado, volumen, retornos logarítmicos diarios y proxies de volatilidad realizada.
- **Noticias geopolíticas:** (Futuro) Titulares de noticias globales y señales de eventos geopolíticos de repositorios abiertos (GDELT / Hugging Face Financial Datasets).

## Instalación y configuración

Para configurar el entorno de desarrollo y comenzar a trabajar, puede seguir los siguientes pasos:

**1. Clonar el repositorio:**

```bash
git clone https://github.com/tu-usuario/brent-crude-volatility-geopolitical-risk.git
cd brent-crude-volatility-geopolitical-risk
```

**2. Recrear el entorno Conda:**

```bash
conda env create -f environment.yml
```

**3. Activar el entorno:**

```bash
conda activate brent-dl
```
